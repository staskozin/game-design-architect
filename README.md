# Game Design Architect

**Версия:** 0.1.0 · **Язык ответов по умолчанию:** русский · **Формат:** portable Agent Plugin без MCP.

Три Skills для системной работы с игровыми механиками. Общая методология отделяет **зачем** механика нужна игроку от **как** она работает технически.

## Режимы

| Skill | Когда используется | Основной результат |
| --- | --- | --- |
| `mechanic-designer` | Придумать или переработать механику | Дизайн механики и его системная декомпозиция |
| `mechanic-analyzer` | Разобрать механику существующей игры | Наблюдения, гипотезы, структура и выводы |
| `mechanic-specification` | Подготовить ТЗ для разработчика/Codex | Однозначные правила, крайние случаи, критерии приёмки |

Режим определяется по намерению пользователя, а не по наличию какого-то ключевого слова. При явно сформулированной просьбе о ТЗ приоритет у `mechanic-specification`.

## Как использовать

Примеры запросов:

- «Спроектируй механику престижа. Сначала предложи 2 варианта, потом разложи выбранный по пяти блокам».
- «Проанализируй Hexa Sort: что там происходит на уровне механик и какие правила создают интерес?»
- «Составь короткое ТЗ для Codex на изменение очереди работников. Без новых игровых решений».

Можно явно выбрать режим словами «проектирование», «анализ» или «ТЗ»; выбор отдельной кнопки не обязателен. Плагин не хранит игровой прогресс и не получает доступ к репозиториям сам по себе: он использует сведения, доступные в текущем разговоре и подключённых инструментах.

## Создание и установка

1. Открой в ChatGPT **Plugins → Plugin Creator** (`@plugin-creator`). Передай ему папку/ZIP и попроси создать или импортировать **skills-only** плагин по файлам, сохранив структуру и `plugin.json`.
2. Если Plugin Creator не импортирует portable-манифест напрямую, попроси преобразовать пакет в поддерживаемый им compatibility layout и создать локальную запись каталога.
3. Проверь выбор всех трёх Skills запросами из `tests/smoke-tests.md`.

Создание папки и ZIP **не равно установке**: публикацию/подключение нужно выполнить в интерфейсе ChatGPT или совместимом окружении. Наличие Plugin Creator и возможность импорта зависят от аккаунта и среды.

## Правила разработки методики

- Единственный источник подробного описания пяти блоков: `references/framework.md`.
- Общие критерии качества: `references/design-principles.md`.
- Skills содержат минимальную достаточную информацию для выбора сценария и ссылки на общие файлы; не копируй весь framework в каждый Skill.
- Тексты в `assets/` — **варианты структуры ответа**, а не обязательная анкета. Не показывай пустые разделы без необходимости.
- Для нового проекта контекст берётся из запроса, а не из иллюстративного примера про котов.

## Что осознанно не входит в v0.1

MCP, API, внешние сервисы, генерация кода, автоматический анализ игрового репозитория, сложные формы, скрипты проверки экономики. Позже их можно добавить как независимые возможности; для методологии они не нужны.
